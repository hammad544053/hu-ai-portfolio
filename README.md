A full-stack, production-grade portfolio and dynamic Content Management System (CMS) built to showcase machine learning models, computer vision pipelines, generative AI frameworks, and technical credentials.

## 🚀 Key Features

- **Dynamic Admin Dashboard (CMS):** Complete CRUD interface protected by Flask-Login to manage projects, engineering pillars, metrics, certifications, and skills without editing code.
- **Automated SMTP Contact Engine:** Directly forwards contact inquiries to Gmail Primary Inbox using RFC 2822 compliant email headers.
- **Responsive Interactive Background:** Custom canvas layer with edge-to-edge full-bleed background styling optimized across desktop and mobile screens.
- **Production-Ready Architecture:** Configured for seamless deployment on Vercel with environment variable security (`.env`).

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-SQLAlchemy, Flask-Login, Werkzeug
- **Frontend:** HTML5, CSS3 (Glassmorphism UI), Modern JavaScript (ES6+), Canvas API
- **Database:** SQLite (Development) / PostgreSQL (Production)
- **Deployment & Security:** Vercel, python-dotenv, SMTP (TLS)

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/hammad544053/YOUR-REPO-NAME.git](https://github.com/hammad544053/YOUR-REPO-NAME.git)
   cd YOUR-REPO-NAME


1. Create and activate a virtual environment:

python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

2. Install dependencies:
pip install -r requirements.txt

3. Set up Environment Variables:
Create a .env file in the root directory:
SECRET_KEY=your_secret_key
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_admin_password
MAIL_USERNAME=your_email@gmail.com
MAIL_PASSWORD=your_gmail_app_password

4. Run the Flask development server:
python app.py
